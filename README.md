# タイムマネジメント v2

旧版 (`time` リポジトリの time.html) はそのまま。これは**保存を強くした改善版**。
見た目・操作は旧版とほぼ同じ (追加は「生産したもの」欄だけ)。

## 旧版から変わったこと

| # | 変更 | 理由 |
|---|------|------|
| 1 | **記録とタグ設定を localStorage + IndexedDB に二重保存** | iPhoneのSafariはしばらく開かないと localStorage を消すことがある。片方が消えてももう片方から自動復元される |
| 2 | **JSONバックアップの書き出し/読み込みを追加** | 旧版のバックアップは「今表示中の週のテキストコピー」だけで全期間を退避できなかった。新ボタンは**全期間の記録+タグ設定**を1ファイルに保存。iPhoneでは共有シートから「"ファイル"に保存」でiCloud Driveに置ける |
| 3 | **PWAを正式な形に (manifest / sw.js / アイコンをファイル化)** | 圏外・機内モードでも開ける。アイコンは旧版のものをそのまま流用 |
| 4 | **各枠に「生産したもの」欄を追加** | 時間を塗るだけでなく成果を残すため。メモモードで枠をタップすると「何してた？」の下に「⇒ 生産したもの」欄が出る。グリッドと分析に黄色で表示され、分析には「生産物」カード (期間の個数) と週の「生産したもの」一覧も出る。全文コピーでは `⇒` 区切りで書き出され、貼り直しても復元される。指標カードは6枚に収めるため「移動」を「生産物」に置き換えた |

データのキー (`tt-state-v1` / `tt-cats-v1`) と形式は旧版と完全互換。
同じGitHub Pagesドメインに置けば、旧版で溜めた記録がそのまま見える。

## デプロイ先 (GitHub Pages)

既存リポジトリ `takemana0011-dot/time` にこのフォルダの中身を置いている
(2026-07 に旧 time.html を v2 で上書き。旧版のコードは git 履歴に残っている)。

- `https://takemana0011-dot.github.io/time/` — 正式なURL (index.html)
- `https://takemana0011-dot.github.io/time/time.html` — 旧URL。同じ v2 の
  コピーを置いてあるので、昔ホーム画面に追加したアプリもそのまま新版になる

URL・ドメインが変わらないため、**データの引っ越しは不要**
(localStorage / IndexedDB のキーと形式が旧版と同じなので、開けば今までの記録がそのまま見える)。
コードを更新するときはこのフォルダを直して `time` リポジトリに反映し、
`sw.js` の `CACHE` を上げる。

## 中身の構成

- `index.html` — アプリ本体 (旧 time.html と同じ構成)
- `sw.js` — オフラインキャッシュ。コード更新時は中の `CACHE` (`time-v2-1`) を上げる
- `manifest.webmanifest` / `icon-*.png` — ホーム画面追加用
